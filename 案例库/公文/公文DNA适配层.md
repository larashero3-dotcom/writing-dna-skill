# 公文 DNA 适配层

> 本文件定义如何将"写作蒸馏器"的 L1-L6 框架适配到公文写作场景。
> 基于 8 篇案例标注提炼。

## 核心差异：公文 vs 自媒体

| 维度 | 自媒体 | 公文 |
|------|--------|------|
| 风格来源 | 个人（每人不同） | 文种+意图+对象（三重决定） |
| L1 价值 | 高（区分不同作者） | 低（语言个性弱，真正区分好坏的是逻辑密度） |
| L2 价值 | 中（结构是风格的一部分） | 极高（结构=决策树，是核心竞争力） |
| L3 含义 | 选题逻辑（写什么） | 站位选择（从谁的角度切入） |
| L5 含义 | 世界观、价值判断 | 政治判断力（力度、分寸、对象感知） |
| L6 价值 | 高（视觉是品牌） | 近零（红头文件格式标准化） |

---

## L1 适配：从"语言指纹"到"力度控制系统"

公文的 L1 不是蒸馏"谁在写"，而是蒸馏"这类文件该用什么力度的语言"。

### 提取维度（替换原 L1）

**1. 刚柔表述分布**

| 力度 | 标志词 | 适用场景 |
|------|--------|----------|
| 强制 | 应当、必须、不得、严禁 | 制度规定、红线要求 |
| 要求 | 要、需要、切实、确保 | 工作部署、任务分配 |
| 建议 | 建议、可以、鼓励、支持 | 政策引导、弹性空间 |
| 期望 | 期望、希望、争取 | 上行文恳请、愿景表述 |

> 关键规则：同一篇文章中，强制词的密度决定了文件的"法律效力感"。#03（人民监督员）中，"应当/不得"出现在核心制度条款，"可以/一般"出现在操作细节——刚性用在边界，柔性用在执行空间。

**2. 数字精度等级**

| 等级 | 表现 | 案例 |
|------|------|------|
| 精确到个位 | "6330多个""220万平方米" | 用于制造压力感（#04 裁执分离） |
| 概数 | "三分之二""90%以上" | 用于快速建立印象（#02 垃圾分类） |
| 范围 | "47.7%-64.9%不等" | 用于体现复杂性（#07 光伏） |
| 不用数字 | 以定性表述替代 | 政治敏感处避免精确（不给人抓把柄） |

**3. 句式节奏**

- 公文平均句长 35-50 字（远长于自媒体的 15-25 字）
- "一是…二是…三是…"并列结构是基础节奏单元
- 短句极少出现，一旦出现即为"发力句"（如"裁执分离是大势所趋"）
- 顿号密集度反映并列枚举的信息密度

**4. 避坑词表**（公文扣分项）

| 禁用 | 原因 | 替代 |
|------|------|------|
| 我觉得/我认为 | 公文不用第一人称主观判断 | 研究认为/实践表明 |
| 非常/特别/极其 | 空洞程度副词 | 用数据或事实替代 |
| 问题很多/困难很大 | 缺乏具体性 | 列举具体问题 |
| 希望领导重视 | 太直白，缺乏论证 | 用论证逻辑自然导向结论 |
| 取得了显著成效 | 万能废话 | 说具体成效是什么 |

## L2 适配：从"结构模板"到"决策树"

公文的 L2 是整个框架的核心价值所在。不是一个文种对应一个模板，而是：

```
文种 × 写作意图 × 行文方向 × 力度等级 = 具体骨架
```

### 决策树入口

```
第一层：行文方向
├── 上行（请示/报告/建议）
│   ├── 要资源 → 骨架 A（政治锚定→沉没成本→痛点→方案→请求）
│   ├── 推制度改革 → 骨架 B（暗含立场：事实铺垫→困境→必然性→建议）
│   └── 摸清现状 → 骨架 C（极简开头→做法→问题→建议）
├── 下行（通知/意见/讲话）
│   ├── 推政策落地 → 骨架 D（先立后破→核心方案→配套→实施）
│   ├── 部署改革试点 → 骨架 E（授权→制度设计→操作流程→保障）
│   └── 动员部署 → 骨架 F（拉近距离→形势→任务→鼓劲）
└── 平行（经验/函/纪要）
    ├── 传授方法论 → 骨架 G（立重要性→分条阐述→素养要求）
    └── 提炼经验 → 骨架 H（结果前置→做法→启示递进）
```

### 8 个已验证骨架（来自案例标注）

| 骨架 | 对应案例 | 核心公式 |
|------|---------|----------|
| A | #08 退耕还林 | `政治锚定 → 历史成效(沉没成本) → 痛点 → 方案+资金 → 配套兜底` |
| B | #04 裁执分离 | `抬高+翻转 → 分场景铺事实 → 困难递进(制度→人身) → 必然性论证 → 恳请` |
| C | #02 垃圾分类 | `一句话开头 → 做法(分地区各取特色) → 问题(标题即判断) → 建议(指定主体+动作)` |
| D | #01 成品油通知 | `回顾成效+暴露问题("但") → 核心调整 → 配套措施 → 一句话实施` |
| E | #03 人民监督员 | `三层授权开头 → 总体要求 → 核心制度(刚柔分布) → 操作流程 → 四元保障` |
| F | #06 绣花功夫 | `亲身经历拉近 → 形势(大→小) → 工作部署(分条) → 情绪推高收尾` |
| G | #05 五要诀 | `文言破题 → 分条(时序排列) → 每条"判断题"式展开 → 素养要求` |
| H | #07 光伏 | `结果前置(时间+金额+结局) → 难度铺垫 → 做法(阶段×维度) → 启示(术→道递进)` |

## L3 适配：从"选题逻辑"到"站位与切入策略"

公文不存在"选题"——题目由工作决定。但存在**站位选择**：同一件事，从什么角度切入。

### 提取维度（替换原 L3）

**1. 站位层级**

| 层级 | 表现 | 案例 |
|------|------|------|
| 国家战略 | 从中央精神/国家战略切入 | #08 "十八大报告提出生态文明建设" |
| 制度完善 | 从法律/制度缺陷切入 | #04 "现有法律法规只规定到…未规定…" |
| 现实需要 | 从基层实际问题切入 | #02 "三分之二的城市面临垃圾围城" |
| 群众视角 | 从百姓感受切入 | #06 "我们一家一户地看、一家一户地听" |

> 规则：站位越高，文件的"格局"越大，但也越空。好公文的技巧是**高开低走**——用高站位破题，用具体数据和事实落地。

**2. 对象感知**

写给谁，决定了：
- 背景铺多少（上级自己知道的不用复述——#02 一句话开头）
- 用什么力度（向上"建议/期望"，向下"要求/通知"）
- 收尾怎么收（上行"请批示"，下行"自发文之日起执行"）

**3. 开头策略矩阵**

| 行文方向 | 策略 | 示例 |
|----------|------|------|
| 上行-要资源 | 政治锚定（引用上级精神建立合法性） | "十八大报告明确提出…" |
| 上行-报问题 | 一句话直入（不浪费决策者时间） | "6月19日至28日，我们赴…调研" |
| 上行-推改革 | 先抬后翻（重要性→危险性→需要关注） | "征收拆迁关系…但…矛盾尖锐" |
| 下行-推政策 | 先立后破（成效→但存在问题→决定调整） | "4年多来…效果显著。但…暴露出…" |
| 下行-部署任务 | 授权开头（依据→决定→目的） | "根据…精神，经…同意，决定…" |
| 下行-动员 | 拉近距离（个人经历/共同经历） | "我在希望村住了3天…" |
| 平行-分享经验 | 文言/金句破题 | "文以载道，文达政通" |

## L4 适配：从"素材策略"到"论证弹药库"

### 提取维度（保留框架，调整内容）

**1. 权威引用层级**

| 层级 | 引用对象 | 效果 |
|------|---------|------|
| 最高 | 中央文件/领导讲话（需精确到文号） | 政治合法性 |
| 高 | 法律法规/司法解释 | 法律合法性 |
| 中 | 兄弟单位做法/试点经验 | 可行性证明 |
| 基础 | 数据/案例/调研事实 | 事实基础 |

**2. 数据的"吓/安"双轨策略**（从 #08 退耕还林提炼）

- **"吓"数据**：用来制造紧迫感（问题有多严重、不改会怎样）
- **"安"数据**：用来降低决策门槛（成本可控、风险可防、已有成功经验）
- 好的政策建议，两类数据交替出现，先让决策者紧张，再让决策者安心

**3. 案例使用规则**

| 场景 | 用法 | 案例 |
|------|------|------|
| 正面 | 泛指（"某地区""部分单位"） | #02 三地各取特色 |
| 负面 | 极端个案（制造情绪冲击） | #04 "汪家正自焚""血拆" |
| 中性 | 列举行为不定性（让读者自己判断） | #04 "地方政府要求法院全程参加…" |

## L5 适配：从"认知框架"到"政治判断力"

公文的 L5 不是"作者怎么看世界"，而是"在这个权力结构中，怎么说话最有效"。

### 提取维度（替换原 L5）

**1. 归因模式**

| 对象 | 归因策略 | 原因 |
|------|---------|------|
| 成绩 | 归组织/领导/制度 | 政治正确 |
| 问题 | 归客观+认识不足（不归具体人） | 避免得罪人 |
| 困难 | 归制度缺陷/历史原因 | 推动改革而非追责 |

**2. 力度梯度判断**

同一个请求，力度可以从"建议考虑"到"必须立即"，选择依据是：
- 紧迫程度（有没有时间窗口）
- 对象权力关系（向上/向下/平级）
- 政治环境（是否有上级精神可借力）
- 前期铺垫是否充分（论证到位可以更强硬）

**3. 收尾分寸感**

| 行文方向 | 收尾策略 | 句式 |
|----------|---------|------|
| 上行-请示 | 请求+留退路 | "妥否，请批示" / "以上如无不妥，请批转" |
| 上行-建议 | 历史必然性>个人请求 | "…是大势所趋" + "衷心期望…" |
| 下行-通知 | 极简落锤 | "自发文之日起实施" |
| 下行-讲话 | 情绪推高 | "让我们…坚决…" |
| 平行-经验 | 展望/谦虚 | "以上做法供参考" |

---

## L6 适配：简化为"格式合规检查"

公文的视觉风格几乎完全由 GB/T 9704 标准决定，不需要蒸馏。

保留项（仅检查合规性）：
- 标题层级：一级"一、"，二级"（一）"，三级"1."，四级"（1）"
- 正文字号：三号仿宋
- 标题字号：二号小标宋
- 页边距：上3.7cm 下3.5cm 左2.8cm 右2.6cm

## 使用方式

### 场景 1：写新公文

1. 确定三要素：文种 + 意图 + 对象
2. 查决策树，定位对应骨架
3. 按骨架展开，参考 L1 力度控制 + L4 论证弹药
4. 用 L5 收尾分寸感收束

### 场景 2：蒸馏某机关的公文风格

1. 收集该机关 20+ 篇公文
2. 用适配后的 L1 提取其力度偏好（是偏刚还是偏柔？）
3. 用适配后的 L2 归纳其常用骨架变体
4. 用适配后的 L3 分析其站位习惯（总是从什么层级切入？）
5. 用适配后的 L4 分析其论证偏好（数据密集型？案例驱动型？政策引用型？）
6. 整合为该机关的 Writing-DNA.md

### 场景 3：评价/改进一篇公文

对照案例库中同类型文章的标注，检查：
- 骨架选择是否正确？
- 力度是否匹配行文方向？
- 开头策略是否最优？
- 数据/案例是否在"发力"而非"堆砌"？
- 收尾分寸是否得当？

## 与原框架的关系

此适配层**不替换**原框架，而是**在公文场景下重新定义每层的提取目标**：

| 层 | 原框架目标 | 公文适配目标 |
|----|-----------|-------------|
| L1 | 识别个人语言风格 | 识别力度控制系统 |
| L2 | 归纳文章结构模板 | 构建决策树（文种×意图×对象） |
| L3 | 归纳选题逻辑 | 归纳站位与切入策略 |
| L4 | 归纳素材偏好 | 归纳论证弹药组合 |
| L5 | 提炼认知框架 | 提炼政治判断力规则 |
| L6 | 提炼视觉风格 | 简化为格式合规检查 |

当蒸馏对象是自媒体/个人作者时，用原框架。当蒸馏对象是公文/机关文件时，切换到本适配层。
