# 公文写作 DNA 案例库

## 定位

不是格式模板，而是**写作决策链**的拆解。每篇案例回答的核心问题：

- 为什么这样写而不那样写？
- 哪些决策是文种决定的，哪些是意图决定的，哪些是对象决定的？

## 使用方法

1. 按意图或文种找到对应案例
2. 先读"决策链拆解"理解写作思路
3. 用"可迁移骨架"套用到自己的场景
4. 参考"对比标注"避开常见平庸写法
5. 参考"公文DNA适配层.md"理解整体框架
