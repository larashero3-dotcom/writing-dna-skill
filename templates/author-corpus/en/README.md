# Author Corpus Template

Copy this directory to create a separate corpus for each author, publication, or account.

```text
author-name/
├── raw/                    # Complete source articles
├── _meta/                  # Article-level metadata
├── language-dna.md
├── structure-patterns.md
├── cognitive-framework.md
├── visual-style-guide.md
└── Writing-DNA.md
```

Prepare at least 20 complete articles for a reliable style distillation.
